# ClipSync

一个 macOS 菜单栏小工具：

- 插入 SD 卡或 U 盘后，显示设备剩余容量
- 选择一个目标文件夹后，可将照片和视频导入进去
- 支持开启“插入后自动导入”
- 支持按源文件夹名称关键词自动分类视频到指定子文件夹

## 获取方式

源码已经提供在这个仓库里。

如果你只是想直接下载安装 App，不需要安装 Xcode，可以在 Release 附件里下载：

- [ClipSync-1.0.0.dmg](https://github.com/CoimgRain/ClipSync/releases/download/clipsync_v1.0.0/ClipSync-1.0.0.dmg)

如果你想查看源码或自行编译，再按下面的方式运行。

## 从源码运行

1. 用 Xcode 打开这个文件夹里的 `Package.swift`
2. 等待 Xcode 加载完成
3. 选择运行目标 `ClipSync`
4. 点击运行

## 当前行为

- 菜单栏会检测外部可移动存储设备
- 菜单中会显示剩余容量、总容量和容量进度条
- 可开启“插入后自动导入”，检测到新设备后自动开始导入
- “导入照片和视频”当前使用复制方式，不会删除 U 盘或 SD 卡里的原文件
- 导入目录结构为：`目标文件夹/设备名/时间戳/`
- 可开启“文件夹分类规则”：当源文件夹名称中包含你设置的关键词时，命中的视频会自动放入你指定的子文件夹
- 例如你可以把包含某个关键词的素材自动归到 `Pocket`、`Action` 或你自定义的其他文件夹
- 没有命中规则的文件，会继续按默认导入目录保存
- 多条规则支持调整顺序；当同一个文件夹名同时命中多条规则时，会优先使用更靠上的那条
- 遇到同名文件时，可选择“自动重命名保留两份”或“直接覆盖旧文件”
- 每次导入后的目标路径都可以在应用里查看，方便确认文件最后被分到了哪里

## 支持导入的格式

图片：

`jpg` `jpeg` `png` `heic` `gif` `bmp` `tif` `tiff` `raw` `dng`

视频：

`mp4` `mov` `m4v` `avi` `mts` `m2ts` `mpg` `mpeg` `wmv` `mkv`
